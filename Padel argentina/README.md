# Padel Argentina

Sitio web estático del proyecto final del curso de Coderhouse, dedicado a la venta de paletas y artículos de pádel.

## Estructura del proyecto

- `index.html` — Página de inicio
- `pages/productos.html` — Catálogo de paletas y accesorios
- `pages/sobrenosotros.html` — Información sobre la empresa
- `pages/contactos.html` — Datos de contacto
- `pages/ofertas.html` — Promociones y descuentos
- `styles/styles.css` — Estilos del sitio
- `imagenes/` — Recursos gráficos

## Cómo verlo

Abrir `index.html` en el navegador.
